# Calculator Lock App

A calculator app with a hidden vault for storing files. Looks like a normal calculator but entering a secret PIN unlocks the hidden vault.

## Features
- Full functional calculator
- Secret 4-digit PIN protection
- Hide files in vault
- Download and delete files
- Change PIN
- All data stored locally (localStorage)

## How to Use
1. Open the calculator
2. Type your 4-digit PIN and press =
3. Set your PIN on first use
4. Upload files to hide them

## Build APK with Median.co
1. Push this repository to GitHub
2. Go to median.co
3. Connect your GitHub repository
4. Build APK

## Note
- Data is stored in localStorage
- Files are stored as base64 in localStorage
- Maximum storage limit depends on device
